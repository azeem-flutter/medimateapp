# LinkedIn Post Agent

An AI-powered automation that takes a topic and generates a complete LinkedIn post
with visuals using AI, Tavily search, and n8n workflows.

## Features
- Topic → content generation
- Real-time web search with Tavily
- Automated image creation
- Ready-to-publish LinkedIn posts

## Tech Stack
- n8n
- OpenAI / LLM
- Tavily Search
- Image generation API
